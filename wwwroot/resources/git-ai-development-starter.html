Git & AI-Assisted Development — Starter Guide

Safe Git cycle

  1. Create a focused branch.
  2. Inspect with git status and git diff.
  3. Make one coherent change.
  4. Run tests/build.
  5. Commit with a clear message.
  6. Push and review before merging.

Using AI responsibly

  • Give precise requirements and constraints.
  • Review every generated change.
  • Never paste secrets into prompts or source control.
  • Ask for tests and edge cases.
  • Run the project's own validation after AI-assisted edits.
Practice: ask an AI assistant to explain a failing test, propose two fixes, then independently verify the chosen fix.
